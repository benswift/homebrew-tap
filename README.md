# Benswift Tap

## How do I install these formulae?

`brew install benswift/tap/<formula>`

Or `brew tap benswift/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "benswift/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
